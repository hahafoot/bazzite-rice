                              HYPRLAND KEYBINDS
                              =================
                          (press q to close this window)

  Mod = SUPER (Windows key)


  APPS & SESSION
  --------------
    SUPER + RETURN              kitty terminal
    SUPER + SHIFT + RETURN      kitty in the focused Nautilus folder (else plain kitty)
    SUPER + SPACE               rofi app launcher
    SUPER + E                   nautilus (file manager)
    SUPER + G                   Steam
    SUPER + SHIFT + A           add/remove startup apps (rofi menu; removing kills the process)
    SUPER + L                   hyprlock (lock screen)
    SUPER + ESCAPE              wlogout (power menu)
    SUPER + SHIFT + M           exit Hyprland (panic bind)
    SUPER + \                   this cheatsheet


  WINDOWS
  -------
    SUPER + Q                   close active window
    SUPER + F                   toggle fullscreen
    SUPER + V                   toggle floating
    SUPER + ← / → / ↑ / ↓       move focus between tiled windows
    SUPER + LMB drag            move floating window with mouse
    SUPER + RMB drag            resize floating window with mouse


  WORKSPACES
  ----------
    SUPER + 1 ... 9             switch to workspace N
    SUPER + 0                   switch to workspace 10
    SUPER + SHIFT + 1 ... 9     move active window to workspace N
    SUPER + SHIFT + 0           move active window to workspace 10
    SUPER + O                   swap workspaces between DP-1 and DP-2


  WALLPAPERS
  ----------
    SUPER + SHIFT + P           waypaper (GUI picker)
    SUPER + W                   terminal wallpaper picker (kitty + fzf), then:
                                  Enter             span across all monitors
                                  Alt + 1           apply to DP-1
                                  Alt + 2           apply to DP-2
                                  Esc               cancel
    Wallpapers live in: <repo>/wallpapers/ (searched recursively).
    Images use swww, videos (.mp4/.webm/.mkv/.mov) use mpvpaper.


  SCREENSHOTS  (hyprshot)
  -----------------------
    Print                       full monitor → ~/Pictures
    SUPER + Print               active window
    SUPER + SHIFT + Print       region (drag to select)
    SUPER + SHIFT + S           region   (alias of SUPER+SHIFT+Print)


  CLIPBOARD
  ---------
    SUPER + C                   clipboard history popup (cliphist → rofi)


  MEDIA / VOLUME  (work on dedicated media keys)
  ---------------------------------------------
    Volume Up / Down            change default sink volume by 5%
    Mute                        toggle default sink mute
    Mic Mute                    toggle default mic mute
    Play/Pause/Next/Prev/Stop   playerctl (whichever player is active)


  BRIGHTNESS  (external monitors via ddcutil / DDC-CI)
  ---------------------------------------------------
    SUPER + =                   brightness up   (hold to repeat)
    SUPER + -                   brightness down (hold to repeat)
    Brightness Up / Down keys   same, if the keyboard has them


  MAINTENANCE
  -----------
    SUPER + SHIFT + B           restart waybar (status bar)
    SUPER + SHIFT + R           reload workspace-watcher.lua (after editing rules)
    SUPER + CTRL + SHIFT + R    re-apply hyprland.conf (if monitors/binds drop)
    SUPER + SHIFT + D           monitor arranger (GUI: drag/resize/rotate, Save writes monitors.conf)


  WAYBAR CLICKS  (right cluster)
  ------------------------------
    CPU module       left-click  → btop in kitty
    GPU module       left-click  → btop in kitty
    Clock            left-click  → GNOME Calendar
    Media (mpris)    left-click  → play/pause
                     right-click → playing TUI in kitty
                     scroll      → next / previous track
    Pulseaudio       left-click  → pavucontrol (mixer)
                     right-click → toggle sink mute
                     middle-click → toggle mic mute
                     scroll      → volume ±2%
    Network          left-click  → nm-connection-editor
                     right-click → GNOME Control Center → Network
    Tray icons       (per-app menus from nm-applet, blueman, etc.)


  TERMINAL WIDGETS  (run in any kitty window)
  -------------------------------------------
    pomo                        pomodoro + task board (space play/pause,
                                tab cycle session, a add task, x cycle
                                status, d delete, r reset, q quit)
    music                       spotify_player TUI (Premium required)
    viz                         cava audio visualizer
    playing                     now-playing dashboard (space, n, p, [/]
                                seek, s stop, q quit)
    portal                      animated Rick & Morty portal
    cube                        spinning 3D wireframe cube


  RESCUE (if Hyprland gets weird)
  -------------------------------
    Symptom: SUPER keybinds stop working AND/OR a monitor drops to the wrong
    position/refresh-rate. This usually means hyprland.conf reverted to
    built-in defaults. Verify with: `hyprctl getoption general:border_size`
    -- if it shows `set: false`, the config is not applied.

    Fix from any terminal:
      hyprctl reload                           # re-apply hyprland.conf  (primary fix)
      hyprctl dispatch submap reset            # free a stuck submap
      hyprctl keyword monitor "DP-2, ..."      # one-off monitor override
      ~/.config/hypr/reload-watcher.lua        # restart workspace-watcher

    If even your terminal is unreachable, drop to a TTY (Ctrl+Alt+F3),
    log in, and: `hyprctl -i 0 reload`
